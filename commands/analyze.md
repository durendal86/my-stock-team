운용역을 위해 **$ARGUMENTS** 종목을 종합 분석합니다. 대상은 대형주 위주입니다.

## 라우팅 규칙 (질문 유형 → 담당)

- 재무·실적·공시(매출·영업이익·분기보고서 등) → `fundamental-analyst`
- 가격·추세·거래량(주가·이동평균·52주 고저 등) → `market-tech-analyst`
- 뉴스·이슈·시장 심리(악재·호재·여론 등) → `news-sentiment-analyst`
- "분석해줘" 같은 종합 요청 → 위 3명 모두 실행 후 `risk-manager-synthesizer`가 종합
- 종목·범위가 모호하면 추측하지 말고 **먼저 되묻습니다.**

## 실행 흐름 (종합 분석)

1. **1단계 — 병렬 분석.** `fundamental-analyst` · `market-tech-analyst` · `news-sentiment-analyst`를 **한 메시지에서 동시에(병렬)** 호출합니다. 셋은 입력 의존성이 없습니다. 각 에이전트에 종목명/코드와 기준일(오늘)을 전달하고, 결과가 5부 리포트의 ②재무 / ③차트 / ④·⑤뉴스·심리 파트로 쓰임을 알립니다.
2. **2단계 — 리스크 종합.** 1단계 3인의 산출물을 **반드시 전달**하며 `risk-manager-synthesizer`를 호출합니다. 일부 입력이 빠지면 무엇이 누락됐는지 명시하고 가용분으로만 종합합니다.
3. **3단계 — 리포트 작성.** 결과를 `reports/$ARGUMENTS.md`로 저장합니다. 포맷은 `/build-report`가 읽는 구조(프런트매터 + `## 종목 개요 / 재무 요약 / 가격·추세 / 뉴스·심리 / 리스크 / 한 줄 종합`)를 따릅니다.
4. **4단계 — 검증·산출.** 이어서 `/verify-report $ARGUMENTS`로 품질을 점검하고, **통과** 시 `/build-report $ARGUMENTS --pdf`로 디자인 PPTX·PDF를 만듭니다. **보류**면 지적 사항을 반영해 .md를 고친 뒤 다시 검증합니다.

## 가드레일 (항상 적용)

- 모든 수치 옆에 `(출처: 데이터명, 연도/날짜)`. 출처 없는 수치는 쓰지 않습니다.
- 못 구한 값은 **"확인 불가"**, 출처 없는 뉴스·루머는 **"미확인"**으로 표기합니다.
- 매수·매도·보유·목표가·비중 조정 등 투자 행동을 **단정하지 않습니다.** 판단 근거 정리(의사결정 지원)까지만, 최종 판단은 사람입니다.
- 데이터 소스 분담: 재무=DART, 시세·추세=FinanceDataReader, 뉴스·심리=웹서치, 시총·거래대금=pykrx. 리서치 헤드가 직접 수치를 만들지 않습니다.
- 문체는 "~입니다" 체. 리포트 첫머리에 "무료 공개 데이터 기반 학습용" 한 줄, 끝에 데이터 출처·기준일 목록을 둡니다.
- `DART_KEY` 등 비밀값은 출력·로그에 노출하지 않습니다.
