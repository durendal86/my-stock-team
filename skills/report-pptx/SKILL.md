# report-pptx

`reports/{종목명}.md` 한 개를 읽어 **디자인된** `reports/{종목명}.pptx`를 만든다.
렌더링 코드는 `build.py`에 있고, 모델은 입력 .md를 준비/검증하고 스크립트를 실행한다.

## 실행 방법

```bash
python .claude/skills/report-pptx/build.py reports/{종목명}.md          # PPTX만
python .claude/skills/report-pptx/build.py reports/{종목명}.md --pdf    # PPTX + PDF
```

`--pdf`는 `pdf-convert` 스킬(LibreOffice 헤드리스)을 호출해 같은 폴더에 `.pdf`를 함께 만든다.

종목명만 주어지면 `reports/{종목명}.md`를 입력으로 가정한다. 파일이 없으면 사용자에게
경로를 확인하고, 필요하면 아래 포맷으로 .md를 먼저 작성한다.

## 슬라이드 순서 (항상 고정)

1. 표지 (종목명 · 작성일)
2. 종목 개요
3. 재무 요약 (표 + 최근 3개년)
4. 가격 / 추세 (차트)
5. 뉴스 · 심리
6. 리스크
7. 한 줄 종합

## 입력 .md 포맷

프런트매터 + `##` 섹션 헤더. 섹션 제목은 별칭을 허용한다(개요/재무/가격·추세/뉴스·심리/리스크/한 줄 종합).

```markdown
---
종목명: 삼성전자
종목코드: 005930        # (선택) 있으면 FinanceDataReader로 6개월 가격·이평 차트 자동 생성
작성일: 2026-06-11
---

## 종목 개요
- 한 줄 소개와 사업 구성 …

## 재무 요약
| 항목 | 2023 | 2024 | 2025 |
|---|---|---|---|
| 매출액 | 258.94조 | 300.87조 | 333.61조 |
| 영업이익 | 6.57조 | 32.73조 | 43.60조 |
(출처: DART, 각 연도 사업보고서 / 기준일 2025-12-31)

## 가격/추세
![chart](.charts/직접이미지.png)   # (선택) 직접 이미지. 없고 종목코드가 있으면 자동 차트.
- 추세 코멘트 …  (출처: FinanceDataReader, 기준일 2026-06-11)

## 뉴스·심리
- 핵심 이슈 … (출처: 매체, 날짜)
- 종합 심리: 중립 …

## 리스크
- ① … / ② … / ③ …

## 한 줄 종합
펀더멘털·밸류에이션·리스크를 종합한 한 문장 (매매 단정 금지)
```

- 재무 표의 연도 열이 4개를 넘으면 **마지막 3개년**만 싣는다.
- `가격/추세`에 이미지가 있으면 그대로 삽입하고, 없고 `종목코드`가 있으면 차트를 자동 생성한다(네트워크 실패 시 본문만 렌더).

## 디자인 규칙 (build.py에 구현됨)

- 포인트색 **KB 옐로우 `#FFBC00`**, 본문은 그레이/화이트의 차분한 금융 리포트 톤.
- 한글 폰트는 **맑은 고딕** 하나로 고정 (latin/ea/cs 모두 지정 → 글자 깨짐 방지).
- 와이드(16:9), 상단 옐로우 액센트 바 + 하단 푸터(학습용·기준일).
- 표는 슬라이드 밖으로 잘리지 않게 행 수에 따라 폰트를 줄이고, 한계 초과 시 행을 줄이고 주석을 단다.

## 가드레일 (출력 전 확인)

- **모든 수치 옆에 (출처/기준일)** 표기. 출처를 댈 수 없는 숫자는 .md에 넣지 않는다.
- **매수·매도·목표가 단정 금지.** 판단 근거까지만. `build.py`가 금지 표현을 스캔해 경고하지만,
  최종 점검은 모델이 한다 — 경고가 뜨면 해당 표현을 고친 뒤 다시 생성한다.
- 리포트는 학습용임을 전제로 한다(푸터에 명시됨).
