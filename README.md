# my-stock-team 📈

**"삼성전자 분석해줘" 한마디면, 여러 명의 AI 애널리스트가 나눠서 조사하고 발표 자료(PPT·PDF)까지 만들어 주는 도구입니다.**

재무·주가·뉴스·위험요인을 각각 담당하는 AI들이 동시에 일하고, 그 결과를 깔끔한 리포트 한 부로 정리해 줍니다.

> 이 도구가 만든 내용은 **공개된 무료 데이터로 만든 학습·참고용**입니다. "사라/팔라" 같은 투자 권유는 하지 않으며, 최종 판단은 본인이 하셔야 합니다.

---

## 🧩 먼저, 이게 뭔가요?

- 이건 **Claude Code**라는 프로그램 안에서 쓰는 **플러그인**(기능 추가팩)입니다.
- 비유하자면, 카카오톡에 이모티콘을 설치하듯이 — Claude Code에 "주식 분석 팀" 기능을 끼워 넣는 것입니다.
- 그러니 **Claude Code가 먼저 깔려 있어야** 합니다. (회사에서 안내받은 설치 방법을 따라 설치해 두세요.)

---

## 1️⃣ 설치하기 (딱 두 줄)

Claude Code를 켜고, 화면 아래 **입력창에 아래 두 줄을 한 줄씩 그대로 복사해 붙여넣고 Enter**를 누르세요.

```
/plugin marketplace add durendal86/my-stock-team
```
```
/plugin install my-stock-team@my-stock-team
```

- 첫 줄: "이 도구가 어디 있는지" 알려주는 단계입니다.
- 둘째 줄: 실제로 설치하는 단계입니다.
- 한 번만 해두면 됩니다. 다음부터는 바로 쓸 수 있어요.

---

## 2️⃣ 사용하기 (그냥 말 걸듯이)

설치가 끝났으면, 입력창에 평소 말하듯 적으면 됩니다.

```
삼성전자 분석해줘
```

그러면:
1. 재무 담당, 주가 담당, 뉴스 담당 AI가 **동시에** 조사하고,
2. 위험요인 담당 AI가 그 결과를 모아 정리한 뒤,
3. **표지 → 재무 → 차트 → 뉴스·심리 → 리스크 → 종합** 순서의 리포트를 만들어 줍니다.

다른 종목도 똑같이 하면 됩니다. 예: `SK하이닉스 분석해줘`, `현대차 분석해줘`

발표용 파일이 필요하면 이렇게 말하세요:

```
방금 분석한 거 PPT랑 PDF로 만들어줘
```

---

## 3️⃣ 딱 하나 미리 준비할 것: DART 키 (무료, 5분)

재무 데이터는 금융감독원의 공식 공시 사이트 **DART**에서 가져옵니다. 이걸 쓰려면 **본인 전용 열쇠(키)** 가 하나 필요한데, **무료**이고 발급도 금방입니다. (보안상 이 키는 공유되지 않으니 각자 발급해야 합니다.)

1. <https://opendart.fss.or.kr> 접속 → **인증키 신청**에서 이메일로 무료 발급받습니다.
2. 받은 키를, 분석 작업을 하는 폴더에 **`.env`라는 이름의 메모장 파일**을 만들어 아래처럼 한 줄 적어 저장합니다.

   ```
   DART_KEY=여기에_발급받은_키_붙여넣기
   ```

> 💡 이 키는 비밀번호 같은 것이라 **다른 사람에게 보여주거나 인터넷에 올리면 안 됩니다.** (이 도구는 키를 자동으로 보호하도록 설정돼 있습니다.)

키가 없어도 주가·뉴스 분석은 되지만, 재무 부분은 비어 있게 됩니다.

## ❓ 잘 안 될 때 (조금 기술적인 부분)

대부분은 위 3단계면 충분하지만, 환경에 따라 아래가 필요할 수 있습니다. **막히면 옆의 개발자에게 이 줄을 보여주세요.**

- **Python 패키지**: `OpenDartReader`, `finance-datareader`, `pykrx`, `python-pptx`, `pandas`, `matplotlib`, `pyyaml`
- **PDF 변환**: LibreOffice 필요 — `winget install --id TheDocumentFoundation.LibreOffice -e --silent` (없으면 PPT까지만 생성됩니다)
- **한글 글꼴**: 기본은 윈도우의 **맑은 고딕**입니다. 맥 등 다른 환경에서 글자가 깨지면 개발자에게 글꼴 설정 변경을 요청하세요.

## 무엇으로 이루어져 있나요?

- **리포트 도구 2종** — 발표자료(PPT) 만들기 · PDF로 변환하기

## 이 팀이 꼭 지키는 약속

- 모든 숫자 옆에 **출처와 날짜**를 적습니다. 출처 없는 숫자는 쓰지 않습니다.
- 못 구한 값은 "확인 불가", 소문·미확인 뉴스는 "미확인"이라고 솔직하게 표시합니다.
- **"사라/팔라/목표가" 같은 단정은 하지 않습니다.** 판단에 필요한 근거만 정리하고, 결정은 사람이 합니다.
